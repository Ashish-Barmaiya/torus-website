# Docker Compose Deployment

The repository supplies Docker Compose deployments for local development, demonstrations, and evaluation. The full HTTP stack runs Torus, two mock backends, Prometheus, and Grafana; the HTTPS stack adds mounted TLS certificate and private-key files.

```text
docker/
├── compose.yml
├── compose.full.yml
├── compose.full-https.yml
├── torus/
├── certs/
├── prometheus/
└── grafana/
```

Customize these Docker-specific assets for this deployment; the generic examples under `configs/` are separate.

## Full HTTP stack

Docker and `docker compose` are required. From the repository root, build and start the stack:

```bash
docker compose -f docker/compose.full.yml up --build -d
```

Verify it:

```bash
docker compose -f docker/compose.full.yml ps
curl http://localhost:8080/readyz
curl http://localhost:8080/api/hello
```

View logs or stop the stack:

```bash
docker compose -f docker/compose.full.yml logs -f torus
docker compose -f docker/compose.full.yml down
```

Named Prometheus and Grafana volumes remain unless removed explicitly.

## Full HTTPS stack

The HTTPS deployment uses `docker/compose.full-https.yml`, `docker/torus/torus-https.yaml`, `docker/certs/cert.pem`, and `docker/certs/key.pem`.

```bash
docker compose -f docker/compose.full-https.yml up --build -d
curl -k https://localhost:8443/readyz
curl -k https://localhost:8443/api/hello
```

Use the listener actually configured in `docker/torus/torus-https.yaml`.

## Observability

The full stack exposes Prometheus at `http://localhost:9090` and Grafana at `http://localhost:3000`. With observability enabled, first verify Torus:

```bash
curl http://localhost:8080/metrics
```

For HTTPS, use `curl -k https://localhost:8443/metrics`. In Prometheus, open **Status → Targets** and confirm the Torus target is `UP`, then generate traffic and verify the provisioned Grafana dashboards show current data.

## Development limits

The provided Compose files are not production-ready by default. They use mock backends and source-built images; create a separate deployment architecture for real backend services and production credentials.
